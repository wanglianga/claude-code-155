# 栖兰瑜伽 · 私教体验测评排课续费与转教练协同工作台

城市瑜伽馆私教业务全流程前端：**体验课预约 → 体态评估 → 购课生成课包/排课 → 每节训练记录 → 请假改期 → 续费跟进 → 换教练交接**。会员、教练、顾问三类角色围绕**同一套训练记录**协同，且严格区分销售域与训练域。

技术栈：**Vue 3 + TypeScript + Pinia + Vue Router + Vite**，纯前端 SPA（hash 路由），内置内存数据与种子场景，无需后端即可完整演示。

---

## 一、快速启动

### 方式 1：Docker 一键启动（推荐）

```bash
docker compose up -d --build
# 打开 http://localhost:8080
```

停止：`docker compose down`

### 方式 2：本地 Node 启动

要求 Node.js ≥ 18（开发环境为 Node 22）。

```bash
npm install        # 如遇 npm 缓存权限问题：npm install --cache /tmp/npm-cache
npm run dev        # 开发模式，打开 http://localhost:5173
```

生产构建与预览：

```bash
npm run build      # 先 vue-tsc 类型检查，再 vite 构建到 dist/
npm run preview    # 本地预览生产包 http://localhost:4173
```

## 三、页面与业务流

### 会员端（4 个页面）
1. **我的首页**：课包/剩余课时/有效期、下节课重点（自动承接上节反馈）、训练进展与平均疼痛变化、风险红线、续费提醒、进行中协同事项。
2. **体验课预约**：记录运动基础、身体疼痛、柔韧性、目标、可上课时间、预算、**是否介意异性教练**；体验后可查看教练体态评估（只读）、推荐套餐，**确认购买后自动生成课包、按频次排课、请假规则与到期续费提醒**。
3. **我的课表**：按周查看，可自助**请假 / 临时换时间**（自动校验 24 小时规则、每月 2 次临时改期），查看请假规则与每个课节关联的协同工单进展。
4. **训练记录**：每节课的完成动作、完成度、体感、**疼痛课前→课后变化**、家庭练习、教练备注；可**主动上报身体不适**（自动通知教练顾问并调整下节重点）、**申请更换教练**。

### 教练端（按周教学）
- 按周查看自己的会员卡片：**课程目标、上节课反馈、上节疼痛、本节课重点**、风险数量、待协同数量；周日历显示体验课与常规课。
- 体验课后填写**体态评估、动作限制、禁忌动作、课程建议、风险提示、推荐套餐**——训练域记录，提交即锁定，顾问与会员只读。
- 每节课结束记录完成动作、体感、**疼痛变化**、家庭练习；可勾选「课程进度落后」自动发起协同；课后疼痛 ≥5 且升高时**自动生成不适工单并降阶下节课**。
- 教练提交请假：受影响课节批量挂起、自动通知会员与顾问，不扣课时。

### 顾问端
1. **顾问工作台**：
   - **体验转化**看板（预约总数、转化、流失、转化率）；安排体验课时**强制校验会员的教练性别偏好**；可标记流失并留原因。
   - **续费跟进**：每张续费单先呈现阶段目标完成度、最近 4 节真实训练记录、疼痛变化、缺勤与家庭练习，再谈课包；「有新训练进展」红点提醒；顾问备注保存在独立销售域；办理续费时**旧课包剩余课时自动并入**。
   - **会员总览**：每位会员的课包、最近训练、未结协同数量。
2. **异常协同中心**：统一处理七类工单——🩺身体不适、🏖️教练请假、🕐请假改期、📉进度落后、🔄换教练、⏳课包临期、🚩投诉。每条工单关联具体课节与训练记录，拥有系统动作 + 三方留言的统一时间线：
   - 教练请假 → 选择**改期**或**同性别备选教练代课**（代课/新教练自动获得全部评估与训练记录）；
   - 换教练 → 选择新教练（性别冲突选项禁用），确认后课包与未来课节整体转交，历史评估保留原教练署名；
   - 课包临期 → 到期前 14 天系统自动生成（应用启动时幂等扫描），续费后自动关闭。

### 销售 / 训练边界（核心设计原则）
- 教练的体态评估、禁忌动作、**风险提示只有责任教练能写**；全站没有任何顾问/会员编辑入口，风险块带 🔒 锁定标识与原文展示。
- 顾问的续费沟通有独立备注区，界面强制「**先看训练进展再谈课包**」，并明示不得弱化风险或承诺绕过。
- 投诉工单（何佳佳）演示了边界被破坏后的后果：外呼冻结、主管升级。
- 会员每次疼痛、缺勤、训练效果、课程调整都沉淀为结构化记录，换教练/续费时直接继承，**不从零沟通**。

## 四、推荐验证路径（约 5 分钟走完全部场景）

1. 打开后默认是**林晚晴@会员首页**：查看剩 5 节/12 天到期、右膝不适工单、风险红线、续费提醒。
2. 进 **训练记录**：看到最近一节疼痛 5→6 与教练备注；点「上报身体不适」提交一次（随后在协同中心可见新工单）。
3. 切到**沈若@教练端**：查看林晚晴卡片的「上节反馈/本节重点」；本周四/周五课可点「填写课后记录」，把课后疼痛拉到 ≥5 提交，观察自动工单与下节课重点变化；点「我要请假」提交一次，观察课程挂起。
4. 切到**许岚@顾问工作台 → 协同中心**：
   - 处理苏晓的**换教练**工单（交接给唐柠，回教练端切到唐柠可见课程已转入）；
   - 处理陈默的**教练请假**工单（选代课或改期）；
   - 查看林晚晴的膝盖工单与课包临期工单时间线，留言跟进。
5. 回**顾问工作台 → 续费跟进**：打开林晚晴，先看到疼痛趋势与最近记录，再点「办理续费」，确认剩余 5 节并入新课包、临期工单关闭。
6. 切到**叶知秋@会员 → 体验课预约**：全新问卷提交；再切**罗景@顾问**安排体验课（尝试为介意异性的会员选异性教练会被拦截）；切**教练**填体态评估；最后切回会员确认购买，观察课包、排课计划、请假规则、续费提醒一次性生成。

## 五、本地开发与自动化验证

```bash
npm run typecheck    # 仅 TypeScript / 模板类型检查（vue-tsc）
npm run build        # 类型检查 + 生产构建
npm run test         # 两层自动化冒烟测试（无需浏览器）
```

测试说明：

- `npm run test:logic` — Pinia store 业务规则测试（SSR 构建后在 Node 运行），**29 项断言**，覆盖：性别偏好拦截、评估锁定、购课自动排课、疼痛升高自动工单与下节降阶、请假/改期补排、教练请假挂起与代课、换教练档案完整交接、续费剩余课时并入与临期工单关闭等。
- `npm run test:dom` — 基于 happy-dom 挂载完整应用，切换全部 11 个身份/路由并做真实点击，**30 项断言**，保证三端页面渲染与弹窗交互无运行时错误。

> 说明：本项目为前端工程，数据保存在内存（Pinia + 种子数据），刷新后恢复初始场景；日期按「当前自然周」动态生成，任何一天打开都有本周/上周/下周数据。按任务约束，纯前端项目不提供 Swagger/OpenAPI。
